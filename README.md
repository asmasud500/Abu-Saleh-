# Abu Saleh — Professional Business Portfolio

A modern, responsive business portfolio website built with plain HTML, CSS and JavaScript.

## Features
- Responsive mobile, tablet and desktop layout
- Sticky navigation with mobile menu
- Business-focused hero, services, selected work and contact sections
- Lightweight — no framework or build step required
- SEO-friendly title and description

## Run locally
Open `index.html` in any modern browser.

## Customize
Edit the text in `index.html` and visual design in `style.css`.

## Deployment
The repository is ready for static hosting such as GitHub Pages.
